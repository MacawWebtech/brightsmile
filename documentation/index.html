1. Introduction & Template Overview

Stackly Dental Clinic is an ultra-premium, production-grade HTML5/CSS3/JavaScript website and clinical management template engineered for modern dental practices, oral surgeons, orthodontists, and dental hospital networks.

Key Spec: Built with semantic HTML5, modern CSS3 custom properties (variables), zero heavy third-party framework dependencies, and pure modular ES6+ JavaScript.

5. Global Layout, 30px Padding & 8px Scale

All sections span 100% width with mandatory 30px left and right padding on desktop & tablet screens (adapting to 16px on mobile screens <640px) via var(--container-padding). Spacing variables strictly use the 8px scale:

--space-1: 4px; --space-2: 8px; --space-3: 16px; --space-4: 24px; --space-5: 32px; --space-6: 48px; --space-7: 64px; --space-8: 80px;

6. FOUC-Free Dark/Light Mode Engine

Dark mode executes synchronously in the <head> before CSS rendering, preventing Flash of Unstyled Content (FOUC). Preferences persist in localStorage:

<script> (function() { var theme = localStorage.getItem('stackly_dental_theme') || 'light'; var rtl = localStorage.getItem('stackly_dental_rtl') === 'true'; if (theme === 'dark') { document.documentElement.classList.add('dark-mode'); document.documentElement.setAttribute('data-theme', 'dark'); } if (rtl) { document.documentElement.classList.add('rtl-mode'); document.documentElement.setAttribute('dir', 'rtl'); } })(); </script>

7. True Layout-Level RTL Engine

Full right-to-left mirroring is supported across public pages and dashboards. The brand logo remains anchored on the extreme left of the desktop header per design specification, while navigation, drawers, sidebars, and tables mirror seamlessly.

8. Navigation, Headers & 44px Mobile Drawer

The navigation header features a left brand anchor, centered navigation links, right-aligned theme/RTL toggles, and direct appointment CTA. The mobile hamburger drawer provides comfortable 44px minimum touch targets.

9. 7-Step Interactive Appointment Booking Engine

Located in assets/js/booking.js, the booking wizard manages:

  1. Service Selection (with price and duration badges)
  2. Dentist Specialist Selection
  3. Interactive Calendar Date Picker
  4. Morning & Afternoon Time Slot Selection
  5. Patient Details with email & phone validation
  6. Consolidated Booking Summary Verification
  7. Instant Confirmation Ticket & Session Storage Persistence

10. Patient Portal Architecture (7 Pages)

Provides patients with an intuitive medical management interface:

  • index.html: Overview with 4 stat cards & upcoming visit alerts.
  • appointments.html: Working Reschedule and Cancel modals.
  • treatment-history.html: Interactive Universal Dental Arch (Teeth 1–32) with dynamic diagnostic notes.
  • prescriptions.html: Medication list & Printable Rx Modal.
  • payments.html: Itemized dental statements & Printable Receipt Modal.
  • profile.html: Personal medical info & Delta Dental insurance card.
  • settings.html: Password change, 2FA toggle & SMS reminders.

11. Admin Practice Management Console (11 Pages)

Delivers comprehensive clinical practice operations:

  • index.html: Practice KPI cards & zero-dependency SVG charts.
  • patients.html: EDR directory & Add Patient Modal.
  • doctors.html: Specialist roster, shifts & Add Doctor Modal.
  • services.html: CDT procedure codes & Add Service Modal.
  • appointments.html: Operations manager & Assign Doctor Modal.
  • treatments.html: Multi-stage procedure progress tracking.
  • prescriptions.html: e-Prescribing & Issue Rx Modal.
  • payments.html: Practice billing & insurance claims (ERA 835).
  • messages.html: Emergency triage communications center.
  • reports.html: Procedure distribution progress bars & CSV export.
  • settings.html: Clinic profile, Tax ID, NPI, and operatory buffers.

13. SEO, Social Meta & Accessibility Compliance

  • Titles: Strictly under 60 characters across all pages.
  • Meta Descriptions: Curated 140–160 character descriptions.
  • Open Graph: Complete og:title, og:image, and og:url tags.
  • Structured Data: DentalClinic JSON-LD schema on all pages.
  • Single H1: Exactly one semantic <h1> per page.
  • Accessibility: WCAG 2.1 AA compliant, ARIA labels, and high contrast.
